# ราชอาณาจักรกัมพูชา — ภูมิศาสตร์ วัฒนธรรม และดนตรีเขมร

สื่อการเรียนรู้แบบเว็บเพจเดียว รองรับการเปิดบนมือถือผ่านการสแกน QR

## หัวข้อ

1. **ลักษณะทางภูมิศาสตร์** — 1.1 ภูมิประเทศ · 1.2 ภูมิอากาศ · 1.3 พืชพรรณไม้ที่สำคัญ
2. **ลักษณะทางวัฒนธรรม** — 2.1 การแต่งกาย · 2.2 ขนบธรรมเนียม ประเพณี การแสดง · 2.3 อาหารการกิน · 2.4 ศาสนา ความเชื่อ
3. **เครื่องดนตรีเขมร** — 20 ชิ้น แบ่งเป็น ดีด · สี · ตี · เป่า
4. **การประสมวงดนตรี** — 7 วง
5. **บทเพลง** — 6 หมวด
6. **บทบาทและหน้าที่ของดนตรีในสังคมกัมพูชา** — 5 บทบาท

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ + SVG นครวัด ลายกระหนก และไอคอนทั้งหมด |
| `assets/style.css` | ธีมสีขาว–ทองวัด และเอฟเฟกต์ |
| `assets/script.js` | ข้อมูลเครื่องดนตรี ภาพประกอบ และการโต้ตอบ |
| `*.jpg` | ภาพเครื่องดนตรีเขมร 20 ชิ้น |

## ที่มาของภาพ

- **ภาพเครื่องดนตรี** — ไฟล์ในโฟลเดอร์นี้ ใช้เพื่อการศึกษา
- **ภาพภูมิประเทศ วัฒนธรรม และอาหาร** — ดึงสดจาก [Wikimedia Commons](https://commons.wikimedia.org/)
  ผ่าน `Special:FilePath` (วางเมาส์บนภาพเพื่อดูหน้าต้นฉบับของแต่ละรูป)

แผนภูมิภูมิอากาศเป็นค่าโดยประมาณ ใช้เพื่อแสดงรูปแบบของฤดูกาลเท่านั้น
